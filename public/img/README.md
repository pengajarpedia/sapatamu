# Gambar SapaTamu

Simpan gambar dengan nama file persis seperti di bawah (huruf kecil semua, format JPG).
Kalau sebuah gambar belum ada, aplikasi otomatis menampilkan ikon cadangan, jadi aplikasi tetap berjalan.
